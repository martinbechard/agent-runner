Concern 01

Foundations

A restrained palette and compact 4px rhythm give Agent Report the character of an evidence instrument: dark structural chrome, paper-like analysis surfaces, cyan action signals, and amber selection.

ColorTypographySpacingShape and motion

Semantic color

Use semantic roles in product components. Amber means selected or emphasized evidence; cyan means action, focus, progress, or quantitative intensity. Red is reserved for error or destructive action.

Target tokens derive from the strongest current roles in styles.css, consolidated for stable semantics.

Typography

Display typography is condensed only for short headings. Controls and prose use the system sans stack; paths, timestamps, numeric evidence, and identifiers use monospace.

Execution summary

Readable body copy explains what the evidence means without competing with exact values.

Floor: persistent metadata is at least 12px with 1.35 line height; body copy defaults to 14px.

Spacing and density

Use a 4px base rhythm. Dense desktop controls use 8–12px internals; sections use 16–32px separation.

4812162432

Shape, elevation, motion

Controls use 3px radii and panels 5px. Borders establish grouping; strong shadow belongs to dialogs and temporary overlays only. Feedback transitions use 120ms and never use transition: all.

Rectangular by default

Instrument controls and data regions are compact, aligned, and restrained.

Elevation is exceptional

Use only when a surface temporarily sits above the task.
