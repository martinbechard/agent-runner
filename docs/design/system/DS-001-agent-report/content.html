Concern 03

Content

Language is direct, operational, and precise. Exact identifiers remain exact; explanations help users interpret evidence rather than decorate it.

Hierarchy

One screen title identifies the task. Section headings name analytical regions. Eyebrows carry short context such as state or observation time, never essential instructions.

Terminology and labels

Use task-specific nouns: “Measure,” “Resolution,” “Visible range,” “Selected period,” “Include child runs,” “Open diagnostics.” Use “Unavailable” for absent evidence and N/A only for inapplicable or unknown capacity.

Actions name outcomes

Use “Generate report” and “Retry search,” not “Submit” or unlabeled symbols.

Evidence stays exact

gpt-5.6-sol, timestamps, paths, IDs, and error codes use monospace and are never prettified into ambiguity.

Ranges state boundaries

When interpretation depends on it, say that the end time is exclusive.

State writing

Empty text names the scope and a safe next action. Errors name the failed operation, preserve usable context, and offer recovery. Partial data states what is missing.
