Concern 09

Approved variations

Variation is intentional only when task, density, state, or platform behavior requires it. Cosmetic alternatives do not create new patterns.

Allowed variants

These variants preserve one semantic contract while changing presentation for a clear product need.

FamilyApproved variantsInvariant
ButtonPrimary, secondary, text, destructive, iconOutcome label, focus, disabled behavior, target size

Mandatory convergence

All product surfaces share semantic colors, type floors, focus treatment, button hierarchy, state language, responsive targets, and dialog behavior.

Current inconsistencies and the work needed to converge are tracked only in DSM-001. They are not alternate designs.

Extension rule

A new token or variant needs a product-critical state or at least two credible consumers. Document anatomy, states, responsive behavior, accessibility, and prohibited uses before adoption.
