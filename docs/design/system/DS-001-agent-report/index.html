Agent Report
Design System

The visual and interaction authority for the catalog, search and scope workflow, run browser, Dynamic Workspace, analytical surfaces, dialogs, exports, diagnostics, and every responsive state.

Product character

A calm technical instrument for examining agent execution. Evidence is prominent, uncertainty is explicit, and dense data stays legible without resembling a generic administration dashboard.

Evidence before decoration

Values, provenance, state, and recovery actions outrank flourish.

Dense, never cramped

Analytical density has hard floors for text, focus, and touch.

State is redundant

Color is reinforced by words, borders, patterns, or shape.

Comparison is honest

Scale, units, range, omissions, and uncertainty are visible.

System concerns

Every page contains approved target rules and live specimens. Current implementation gaps belong in the separate DSM-001 conformance ledger.
