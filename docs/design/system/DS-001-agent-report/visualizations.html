Concern 06

Visualizations

Visualizations make execution patterns legible without hiding exact evidence. The Heatmap is one analytical surface within the larger report system.

Heatmap contract

Intensity is relative within each row. The legend, units, visible range, state key, exact values, and selected evidence are always available.

Responsive and accessible behavior

Row labels remain sticky. Narrow layouts show complete cells with explicit visible-range paging; no overlay obscures a header or cell. Arrow keys move within the grid, Home/End move within a row, and Enter or Space selects.

Exactness

Each cell prints a formatted value; accessible names include measure, row, time, value, evidence state, and scale basis.

Uncertainty

Partial uses amber dashed treatment. Unavailable uses text plus neutral hatching and is never converted to zero.

Modes

Wall time, Tokens, and Models keep stable quantitative semantics. A different hue is allowed only when its meaning is visibly documented.
