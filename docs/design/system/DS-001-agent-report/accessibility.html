Concern 08

Accessibility and responsive behavior

Agent Report remains operable and interpretable with keyboard, assistive technology, zoom, reduced motion, and narrow input devices.

Non-negotiable requirements

Meet WCAG AA: 4.5:1 for normal text and 3:1 for large text and component boundaries. Essential meaning never depends on color, hover, animation, or spatial position alone.

Keyboard

Native controls first; logical order; no trap outside modal dialogs; grid keys follow documented conventions.

Focus

A consistent 3px cyan focus ring with 2px offset remains visible on every surface.

Names

Icon-only buttons, grids, progress, dialogs, and regions have specific accessible names.

Targets

Narrow-screen controls are at least 44px high with 8px between unrelated targets.

Focus specimen

The focus indicator does not depend on browser defaults or cause layout shift.

Reflow, overflow, and motion

At 200% zoom the primary task remains available without two-dimensional page scrolling. Wide data scrolls inside labelled regions. Reduced-motion preference removes decorative transitions; progress remains understandable without animation.

Tooltips may supplement a visible label, never replace instructions or essential evidence.
