Concern 05

Forms and actions

Controls follow the user’s task sequence: define scope, search, select a run, then analyze or export it.

Scope and search

Related fields share a labelled toolbar. Labels remain visible after entry; helper and validation text is programmatically connected.

Action hierarchy

One primary action per task area. Secondary actions use bordered surfaces; destructive actions use explicit language plus red. Symbol-only actions are exceptional.

Segmented controls and toolbars

Segments represent mutually exclusive choices and expose aria-pressed. Toolbars use visible group labels such as Measure and Resolution.

On narrow screens every action is at least 44px high, unrelated targets have 8px separation, and range controls never overlap data.
