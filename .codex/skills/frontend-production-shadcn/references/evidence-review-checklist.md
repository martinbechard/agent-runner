# Frontend Production shadcn Evidence Review Checklist

Use this template for production UI implemented with React, TypeScript,
Tailwind CSS, or shadcn/ui. General product-interface criteria may be applied
to another stack, but mark stack-specific criteria `N/A` rather than pretending
the technology is present. Score each applicable item from 0 to 4 using the
same evidence scale as the owning skill: absent, weak, partial, effective, or
complete. The maximum raw score is 100 before exclusions.
