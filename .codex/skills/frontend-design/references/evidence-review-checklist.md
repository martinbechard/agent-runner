# Frontend Design Evidence Review Checklist

Use this template to review whether an interface has a deliberate,
subject-specific visual identity. Score each applicable item from 0 to 4:

- `0` absent or materially harmful
- `1` weak, generic, or mostly unsupported
- `2` partially effective with notable defects
- `3` effective with minor defects
- `4` deliberate, coherent, and supported by evidence
- `N/A` genuinely outside the reviewed surface; explain why

Every score requires a concrete rendered observation, screenshot reference, or
explicit verification gap. The maximum raw score is 100 before exclusions.
