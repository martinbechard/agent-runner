Concern 04

Data display

Metrics summarize; tables compare; ledgers preserve sequence and evidence. Alignment and labels carry meaning before ornament does.

Summary metrics

Use a compact group only for values that answer one question. Exact numeric values use tabular monospace; labels stay visible.

Tables and ledgers

Headers remain available while scrolling. Text aligns left, comparable numbers right, and timestamps/identifiers use monospace. Rows are 40px compact or 48px standard.

Overflow and density

Inherently wide tables scroll inside a labelled region; the application itself does not. Keep primary identifiers sticky only when it materially aids comparison. Never clip values without a way to inspect them.

Do not encode status with a colored dot alone. Pair it with text and retain visible column headers.
