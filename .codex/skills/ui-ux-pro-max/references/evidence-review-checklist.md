# UI UX Pro Max Evidence Review Checklist

Use this template for a targeted, evidence-backed UI/UX audit. Search the local
database only for concerns that materially apply to the reviewed interface and
record the query and returned rule identity in the evidence. Score each
applicable item from 0 to 4: absent, weak, partial, effective, or complete. Use
`N/A` with a reason for inapplicable items. The maximum raw score is 100 before
exclusions.
